## Emphasis for this posting: skills under dated jobs

This posting's system may extract skills from the CV, match them against the job, and work out experience from job dates. The ground rule still applies:
NOTHING here allows a claim the source CV does not support.

- Name each key skill the posting asks for inside the bullets of the job where the source CV shows it was used, as well as in `skills`.
- Attach a skill to a job only if the source CV links it to that job. If the source lists a skill without saying where it was used, keep it in `skills` alone.
- Use the exact name of the skill as the posting writes it, where it is the same skill. Add a closely related skill from the source CV by its own name; do not present it as the one the posting asked for.
- Name skills explicitly. "Built REST APIs in Go" can be read by a machine; "backend development" cannot be matched to anything.
- Give every experience its `role`, `company`, `start_date` and `end_date`. Years of experience may be computed from these dates, not from what `profile_text` says.
